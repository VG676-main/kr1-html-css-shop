# Лепесток — KR1 (HTML/CSS)

Учебный многостраничный сайт цветочного магазина «Лепесток».

**Контрольная работа №1:** HTML и CSS, семантическая вёрстка, Flex/Grid, БЭМ, форма и модальное окно.

## Структура

```
kr1-html-css-shop/
├── index.html      — главная
├── catalog.html    — каталог
├── product.html    — карточка букета
├── order.html      — заявка
├── contacts.html   — контакты
├── css/style.css
├── js/main.js
├── images/
└── README.md
```

## Технологии

- HTML5
- CSS3 (переменные, Flexbox, Grid, состояния `:hover` / `:focus-visible`)
- Небольшой JavaScript для модального окна и валидации формы
- БЭМ-именование классов

## Как открыть локально

Откройте `index.html` в браузере или используйте Live Server в VS Code.
