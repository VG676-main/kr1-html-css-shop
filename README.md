## Ссылка на сайт

GitHub Pages: https://vg676-main.github.io/kr1-html-css-shop/

## О проекте

Простой сайт без фреймворков: каталог букетов, страница товара, форма заявки и контакты.  
Стили на чистом CSS (переменные, Flexbox, Grid, БЭМ). Небольшой JS только для модального окна и проверки формы.

## Структура

```
kr1-html-css-shop/
├── index.html      — главная
├── catalog.html    — каталог
├── product.html    — карточка букета
├── order.html      — заявка
├── contacts.html   — контакты
├── css/style.css   — стили
├── js/main.js      — модалка и валидация
├── images/         — картинки (SVG)
└── README.md
```

## Технологии

- HTML5
- CSS3 (custom properties, Flexbox, Grid, БЭМ)
- JavaScript (без библиотек)

## Как открыть локально

Откройте `index.html` в браузере или поднимите любой статический сервер в папке проекта.

## Что проверить

1. Переходы между страницами и якорные ссылки  
2. Модальное окно «Быстрая заявка» на главной  
3. Формы на `order.html` и `contacts.html`  
4. Таблицу характеристик на `product.html`  
5. Адаптив на ширине ~768px (сетка карточек)
